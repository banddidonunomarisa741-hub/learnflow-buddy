# LearnFlow学习流动 · Buddy 服务 0.3.0

这是给 Buddy 应用使用的学习服务与对话面板。模型由宿主提供；本服务保存学习偏好、策略、资料与课程记录，不另建模型计费系统。

## 在本机体验

需要 Node.js 24 或以上。在本目录执行：

```text
npm ci
npm run preview
```

打开 `http://127.0.0.1:4318/preview`。顶部可切换学习者、教师和另一位同学，体验逐题选择、策略详情、草稿确认、课程邀请、提交、核验和作业。这三个是本机开发身份；预览页不会自动调用真实模型。按钮请求 AI 时，预览器显示发给宿主的消息，正式宿主应接续对话。

默认数据位于 `%LOCALAPPDATA%/LearnFlowBuddyPreview`。重启保留数据。可通过 `LF_DATA_DIR` 指定独立持久目录。开发模式仅绑定本机回环地址，拒绝代理转发，不能直接暴露到公网。

## 已实现的业务

- 11 张默认策略公开步骤、作者示例与适用边界，用户可随时启停；示例不冒充真实模型输出。
- 学习块和个人策略先进入私人草稿；用户编辑、取消或确认。保存校验版本，旧页面不能批准已经变化的内容。
- 个人策略保留历史版本，用户选择的版本不会因更新草稿而悄悄切换。
- 资料可以再次读取、导出；PDF 由本人选择上传，最大 5 MB，单账号最多 100 份、合计 100 MB。打开采用浏览器预览或下载，不声称云端能启动用户电脑的 WPS。
- 教师创建课程并邀请学生；学生选择提交片段。教师不能查看未提交的个人对话或私人资料。
- AI 分析与针对性作业保持草稿；教师核验和发布后学生才能看到，学生提交后由教师确认完成。
- 策略主动发布后才进入本服务的共享列表，可以撤回。反馈与用户填写的用量属于自报；没有提供方凭据的 Token 不能标成真实计量，也不能作为学习成绩。

课程、分享和资料使用同一服务的数据库。旧网站的浏览器记录、旧本机插件资料和本服务尚未自动同步。

## 服务与授权

`/mcp` 使用标准 Streamable HTTP MCP；`ui://learnflow/workspace.html` 提供自包含 MCP Apps 资源。官方 SDK 已用于真实 HTTP 测试。

模型能读当前选择、查策略、整理草稿、分析已提交证据。保存、课程加入、提交和发布通过面板专用工具执行。专用工具标注 `ui.visibility: ["app"]`，并检查当前授权对应的面板会话令牌。

**面板隔离有宿主前提：**宿主必须遵守 MCP Apps 的可见性和资源隔离，不把面板资源及其会话令牌交给模型。服务端可以验证会话与权限，无法单独在密码学意义上证明“是真人点击”。正式预览必须验证宿主遵守这个边界；不能把本地协议预览当作腾讯客户端验收结果。

服务提供发现、动态客户端注册、S256 PKCE、一次性授权码、刷新轮换和撤销。LearnFlow 令牌只针对本服务和当前用户；上游 WorkBuddy 令牌只用于识别身份，不转发给 MCP 客户端，也不写入学习记录。测试中的上游身份兑换使用隔离模拟，真实平台 OAuth 尚未完成。

## 正式部署

部署模板位于服务 ZIP 根目录，仓库中在 `../connector/remote/`。填写真实 HTTPS 域名、持久目录和已获准的 WorkBuddy 应用凭据。详细字段、控制台回填和审核步骤见仓库的 `docs/BUDDY-CONSOLE-GUIDE.md`。

当前设计适合单实例、挂载持久磁盘的小规模验证。静态 GitHub Pages / Netlify Drop 不能运行这个常驻 Node.js 服务；前端可继续静态托管，后端需支持 Node.js 24 与持久磁盘的平台。可自有服务器加 HTTPS 反向代理，也可选择具备这两项条件的托管平台。

公开服务启动：

```text
node server.mjs --production
```

`/healthz` 表示进程存活；`/readyz` 检查生产模式与凭据配置，不代表真实 OAuth、腾讯审核或模型调用已经通过。不要把示例域名或开发身份用于正式用户。

运营时备份整个数据目录。当前简单且可核验的方式是安排短暂停机后复制完整目录，再启动服务；不要在 SQLite 写入中仅复制一个主文件而遗漏 WAL。部署日志不应记录授权头、授权码、个人对话或环境密钥。扩为多实例之前需更换共享数据库及文件存储，不能让多个实例各保留独立本地盘。

QQ、腾讯会议等能力由用户授权的正式宿主连接器承担。本服务不读取 QQ 登录资料，也不因为生成了提醒文字就记录“已送达”。新应用必须另行完成收发验收；积分和 Token 以平台实际暴露的数据为准，未知保持未知。

## 验证入口

仓库根目录中的 `scripts/test-buddy-store.mjs`、`scripts/test-buddy-service.mjs`、`scripts/test-buddy-oauth.mjs` 验证存储、权限及实际 HTTP/MCP。`scripts/test-buddy-panel.mjs` 使用真实浏览器验证面板操作，报告在 `output/buddy-panel-0.3.0/`。

`scripts/test-buddy-live-model.mjs` 会使用本机 Buddy CLI 产生真实模型用量，应按报告区分模型回复、工具执行与正式宿主展示。它不代表官方 Buddy 应用已发布。发布构建会继续保留未完成的外部条件，而不会生成虚假的通过结果。
