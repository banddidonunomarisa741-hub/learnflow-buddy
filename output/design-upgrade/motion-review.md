# LearnFlow 1.8.0 · 共用视觉与动效检查

范围：仅新增 `public/motion-system.css`、`public/motion-system.js`。根页面最后加载，业务代码未改动。

| 部位 | 原有表现 | 本次处理 |
| --- | --- | --- |
| 聊天与设置 | 多套冷灰、米色和橙色并存 | 统一纸白、暖灰、暖橙；深色使用暖炭色。保留成功/错误的语义颜色。 |
| 主按钮与输入区 | 设置主按钮为黑色，聊天控件有独立硬编码颜色 | 主按钮用暖橙配深色文字，发送用深橙配白字；输入边框、焦点和附件卡跟随主题。 |
| 换页 | 无统一过渡 | 实际路由变化时阅读区一次 200ms 轻微位移/淡入；同路由刷新、正文流式更新、频繁键盘导航不重播。 |
| 弹层 | 弹出缺少方向关系 | 由触发位置确定变换原点，190ms 轻微缩放/淡入；原有 Escape 和关闭行为即时保留。 |
| 指针反馈 | 动作层级不一致 | 按下缩至 .97，抬起可中断；键盘操作不缩放。引导箭头只在精确指针悬浮时轻移。 |
| 提示 | 只有位移 | 进入 200ms、退出 160ms，透明度与位移一致；计时器与文本均由原业务负责。 |
| 减少动态 | 多处 CSS 开关 | 同时支持系统设置与 `html[data-reduced-motion=true]`；立即取消本模块正在运行的 WAAPI。 |

图库 `.sf-gallery`、卡片编辑器 `.card-studio`、教师 `.tc-modal` 与工作区 `.ws-dialog` 等拥有自身动效的组件不叠加全局变换。全局模块不重建、克隆、移动控件，不代理原生 DOM 方法，不发网络请求，不写入持久数据。

验证使用真实 Edge 浏览器和临时只读静态服务，读取当前 `public` 文件。全部 `/api/**` 都由合成数据拦截，没有调用真实模型或 QQ。`test-motion.cjs` 共 **31 项通过**，包括草稿和表单节点保持、同路由不重播、逐题弹层单次入场、搜索模型与 Escape 焦点归还、明暗主题、系统/用户减少动态、移动端边界、组件排除和销毁清理。结果见 `motion-checks.json`。
