# 项目名称与叙事建议

建议保留产品名 **LearnFlow 学习流**，正式申报名使用：

> **学习流——基于可进化学习策略与腾讯 Buddy 生态的自主学习支持平台**

产品的一句话说明：**把适合你的学习方法，变成带得走、用得上、能改进的策略卡。**

答辩记忆句：**选得到方法，留得下证据，带得走经验。**

## 为什么推荐这个名称

“学习流”延续现有材料和六级 Skill 的积累；“可进化”落到用户确认记忆、个人卡片版本与复用反馈，而非宣称训练了模型；“自主学习支持”覆盖应试、自学和 PBL，也容纳学生主动提交的教师评价。“腾讯 Buddy 生态”说明命题适配方向，不预先冒充腾讯官方产品。

这个名称在尚未取得主体认证时仍可对应独立开源网页和可导入策略包，获得发布资格后可对应 Buddy 应用；后续企业合作时也可作为 LearnBuddy 的学习策略模块。品牌名不依赖某个接口、模型或公司审批结论。

这里采用“品牌名 + 破折号 + 机制与场景”的表达习惯，是为评委快速理解，并非声称这是获国奖的命名规则。以下均未完成商标、域名及平台重名检索。

## 进可攻，退可守的三种表述

**当前可交付**：学习流是一套本地运行的学习策略工作台与开放策略包，演示从目标到证据再到个人卡片的完整流程。

**Buddy 发布路径**：以同一策略与数据内核封装 Buddy 应用，在官方支持的宿主和权限内接入模型及连接器；开发完成、账户认证、平台审核分别留证。

**企业合作路径**：向腾讯提交校园场景样例、学习卡规范、回归评测集和真实试点报告，争取内化为 LearnBuddy 可选模块；是否采纳由企业决定。

## 不建议用于名称或主标语

- “腾讯官方”“腾讯联合研发”：没有授权与合作证据。
- “首创”“全国第一”“全面替代教师”：没有对应证明，也偏离学生自主权。
- “大模型认知引擎”“MCP 自进化大脑”：容易把协议适配包装成底层模型创新。
- “全学段全场景”“教育平权已经实现”：可以作为长期愿景，不应替代首轮大学生验证范围。
- “不注册公司就永远不能做”：工程原型与上架资格不是同一问题，具体资格以官方当期规则为准。
