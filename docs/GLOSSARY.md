# LearnFlow学习流动：这些词是什么意思

不需要先学会这些词才能使用产品。网页里尽量用“学习方法”“连接 QQ”“保存资料”；下面这张表供团队开发和与腾讯沟通时查阅。

|词|用普通话说|在 LearnFlow 中是什么|
|---|---|---|
|MVP|能让人完成核心任务的第一版产品|能选方法、提问题、读资料、保存学习结果；不是只有按钮的效果图。|
|宿主|负责运行扩展的应用|LearnBuddy / WorkBuddy。插件要由它发现、加载、调用。|
|Agent / 智能体|能根据任务选择步骤和工具的 AI 助手|根据学习进度提问、讲解、练习；有工具权限时才执行对应操作。|
|Skill / 技能|一份告诉 AI 什么时候、怎样做事的说明|“六级错题复盘”“词根词缀记忆”“直接讲重点”。对用户称学习策略卡。|
|插件 / 专家包|把相关能力装在一起的安装包|可以包含专家说明、Skill、图标和工具配置。能装不等于一定经过官方审核。|
|连接器|给 AI 增加一项外部能力的入口|连接 QQ、文档或学习资料服务；各自需要对应权限。|
|MCP|让不同 AI 应用按同一种方式调用工具的协议|AI 可以调用“查策略”“读学习块”等工具，不必为每个平台重写工具接口。|
|MCP Server|实现这些工具的程序|可以在用户电脑运行，也可以在服务器运行；名称中有 Server 并不等于要租机器。|
|MCP Apps|让工具在支持它的宿主里显示交互面板的方式|可用于策略选择、资料列表或确认保存；实际界面范围要看宿主支持。|
|API / 接口|程序之间约定好的请求方式|网页请求模型回复，QQ 机器人请求发送消息。|
|SDK|平台提供的一套现成开发工具|帮助程序连接 QQ 网关、处理事件和刷新授权。|
|OAuth|用户去服务方确认“允许这个应用做哪些事”的授权流程|例如在官方登录页同意读取指定资料。它不是账号密码，也不是腾讯给所有开发者的免费算力通行证。|
|Scope / 授权范围|一次授权允许做哪些事|只读资料与发送消息是不同能力，产品应说清楚。|
|Access Token / 访问令牌|授权后发给程序的临时通行证|程序用它调用服务；不应出现在截图、聊天、开源仓库或浏览器网址里。|
|Refresh Token|用来续期访问令牌的凭据|仍属于秘密，不能当作普通配置公开。|
|Token / 模型用量|模型计算文字或图片时使用的计量单位|用量与费用有关，不表示学会了多少；它和访问令牌不是同一种东西。|
|AppID / Client ID|应用的身份编号|服务方用它识别“是哪个应用在请求”。它不能代替用户授权。|
|AppSecret / Client Secret|证明应用身份的秘密|像应用自己的密码。放在受控的本机或服务端，不能塞进网页源码。|
|回调地址|用户授权完成后，结果要送到的地址|必须与平台登记一致；不能随便填一个网址。|
|PKCE|防止别人拿走授权码后冒领通行证的校验方式|用户通常不需要操作，开发者要在授权程序中正确实现。|
|二维码绑定|用户用自己的账号扫码并确认连接|二维码只是入口；绑定是否成功仍需查询真实结果。|
|WebSocket|程序与服务保持的一条双向连接|QQ 发来新消息时，电脑上的程序可以立即收到；电脑离线时不能假装仍在处理。|
|stdio|程序通过标准输入输出交换消息|本地 MCP 常用；打开命令行没有普通窗口是正常现象。|
|HTTPS|加密的网络连接|远程接口的基本要求。HTTPS 本身不代表已经授权。|
|前端|用户看到和操作的界面|网页的聊天区、模型面板、策略卡和资料库。|
|后端|负责处理请求、凭据与数据的程序|模型适配、QQ 接收与提醒、资料保存。它也可以在用户本机运行。|
|部署|让程序在目标环境能持续运行|把网页放到静态站，或把服务安装在电脑/云端。|
|静态托管|负责分发 HTML、图片和脚本的网站服务|GitHub Pages、当前 Netlify 演示。不能仅靠静态文件持续收 QQ 消息。|
|JSON|一种结构化的文本格式|应用配置、策略导出和接口消息使用它；自写 JSON 不自动等于平台认可的配置。|
|流式回复|模型生成一段，界面就显示一段|减少等待整篇回答时的空白，并允许用户停止。|
|沙箱 / 测试环境|用于验证功能、限制影响范围的环境|测试机器人或应用预览；测试权限和正式发布权限可能不同。|
|发布审核|平台检查主体、内容与能力后决定是否公开|公司注册、开发者认证、应用审核是不同环节。|
|回归测试|改完后重跑关键操作，确认原有功能没坏|检查连接、读图、停止、保存、恢复和未授权请求。|

Skill 负责学习方法，MCP 提供可调用的工具，OAuth 负责某些外部服务的授权。它们解决不同问题，不需要把 Skill 改名为 MCP，也不能用一个接口代替用户同意。

参考：[腾讯 Buddy 应用](https://open.workbuddy.cn/docs/buddy-app)、[连接器](https://open.workbuddy.cn/docs/connector)、[第三方应用](https://open.workbuddy.cn/docs/third-party-app)。
