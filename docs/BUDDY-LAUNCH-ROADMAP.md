# LearnFlow学习流动：企业认证等待期的推进路线

核验日期：2026-09-06。根据本次对话：公司正在注册审核，企业开发者认证尚未完成，产品主线确定为腾讯 Buddy 应用。下列开发范围和安排是建议，不是平台授予的权限或上线承诺。

## 当前判断

继续推进，认证和开发并行。暂缓独立网页的大幅扩建，把现有成果迁移为宿主内可验证的学习流程。网页用于展示设计与验证交互；配置源稿尚不是腾讯正式导出的应用，也不能上传网页就替换宿主全部界面。

现有资产：正式名称与 F 标志、网页 MVP、解决方案、16 页答辩演示、11 项技能、4 个专家候选、12 项 MCP 工具与学习面板。插件已经通过正常命令安装到 LearnBuddy；QQ 扫码已接通腾讯网关。当前没有公共策略社区或云同步，网页和宿主资料分别保存。实际验证与安装步骤见本轮交付说明。

## 核实结果

- 官方开放平台具有个人与企业认证，但本次未找到完整 Buddy 创建/发布权限矩阵。以当前账号被企业认证阻挡的实际情况作为现阶段约束。[入驻指南](https://open.workbuddy.cn/docs/onboarding)
- Buddy 是宿主内的行业配置，支持模式、场景、模型与生态资产。文档提到 MCP Apps，但不保证任意网页或所有自定义控件可直接嵌入。发布需经历创建审核、配置、指定客户端预览及配置审核。[Buddy 文档](https://open.workbuddy.cn/docs/buddy-app)
- 官方连接器支持本地 stdio 和远程 HTTPS MCP。普通本地连接器与应用首次进入自动启用的内置连接器要求不同；后者的 Buddy 文档要求 OAuth，另有条件式跳过绑定的表述，应要求平台确认具体组合。[连接器](https://open.workbuddy.cn/docs/connector)
- 个人教育类目仅列教育信息展示，不能据此认定交互式学习和公开策略社区已获准。企业“教育平台”有特定服务定义，应按真实功能核实类目。[个人类目](https://open.workbuddy.cn/docs/service-categories-individual)、[非个人类目](https://open.workbuddy.cn/docs/service-categories-enterprise)
- 本次未确认算力由谁付费、是否有应用配额、内测白名单、主体迁移以及最终分发链接的规则。开源免费不等于免审核或模型推理零成本。

## 建议的首版验收

先完成“六级阅读复盘”一个完整流程，再复制到自学与 PBL。保留三个场景的架构，但集中打磨一个可验收样例。

1. 在实际 WorkBuddy 宿主中安装 Skill 和普通本地 MCP，另一台测试电脑可复现。
2. 输入题目与用户答案，先收集证据，再诊断问题；不把材料里的指令当成用户授权。
3. 支持逐题选择偏好，允许跳过或改写，不要求用户懂 Skill 或接口参数。
4. 产生一次练习和可检查的学习块；用户确认后保存指定目录，能够重新打开。
5. 先生成个人策略草稿，确认后才保存，可修改、删除和导出。
6. 至少两个模型测试相同样例；记录错误、耗时和用户完成情况，而非单纯按 Token 判断学习成效。
7. 权限允许后取得官方导出 JSON、真实资源 ID、预览入口与录像。没有平台权限时，验收仅称组件宿主验证，不能称完整 Buddy 预览。

## 后端分阶段

|阶段|部署建议|维护内容|
|---|---|---|
|宿主内测|Skill＋本地 stdio MCP；无需自租云端计算服务器|安装升级、固定版本、文件授权、导出与恢复、异常提示|
|需要公共策略库|增加一个 HTTPS MCP/API 服务及数据库|账号鉴权、策略版本、提交与审核、收藏反馈、限流、监控、备份、删除请求|
|需要跨设备资料|再加对象存储及任务处理|访问控制、配额、文件大小、保留时间、故障重试、成本告警|

“算法服务化”的建议实现：将策略推荐、复习安排、学习块校验等变成有输入输出的工具；模型负责理解与表达，工具负责可复现的计算和持久状态。不要把自购 GPU、自建模型或把桌面桥接程序搬到云端当作默认前提。

如果要租云资源，先部署可复现的服务，再按实际连接数、内存和存储量选最小规格；按月或按量试用，设置预算上限，不预购长期大套餐。公共素材与私人学习记录分开；公共上传先进入审核队列。算力结算未确认前，不承诺无限免费模型调用。

## 付费开发者的采购范围

可以付费请熟悉 WorkBuddy/MCP 的开发者做限定范围的技术验证。不建议只买后台截图：截图不能证明你们的学习流程可运行。

首单交付物建议为：一个真实宿主学习闭环、可复现源码和安装说明、实际支持的 UI 能力清单、权限允许时的脱敏官方导出 JSON、已知限制，以及远程 MCP 部署方案。按里程碑验收，不将“必过审核”写成技术能力。企业主体、仓库、域名和云资源由团队掌握；如由合作方主体发布，先明确应用归属和是否支持迁移，不能默认以后无损转回。
