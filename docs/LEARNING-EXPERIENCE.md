# 学习路线、学习块与学习资产

## 首次使用

没有完成初始化的浏览器首次打开页面，会自动弹出七道逐题选择：学习场景、当前目标、可用时间、引导程度、交流方式、支持偏好、是否开启学习记忆。用户可以返回上一题、填写自己的目标，或使用推荐路线直接开始。完成后展示一次操作指引。首页的“调整我的学习路线”始终保留。

## 回答后继续学习

真实模型可以返回 2–3 条与本轮内容及已启用策略相符的建议。界面把建议与正文分开呈现，支持直接发送或改写；含明显待填写占位符的建议会先进入输入框。模型没有返回可解析建议时，使用当前场景、策略、最近问题和交流偏好构成起步选项，不冒充模型推断。

模型认为阶段内容适合整理时提出学习块草稿；未返回标记时，页面只对多轮且包含回顾/练习要点的较长真实回答提供规则提示。这不表示用户已掌握知识。用户可以修改、忽略或确认保存；忽略后至少间隔两个对话轮次再作规则提示，用户主动要求总结除外。学习块与个人偏好记忆分开，保存学习块不会自动开启学习记忆。顶部保留主动整理入口。

## 学习资产

- 回答下方“保存为学习资料”，或“看看总结草稿”：先编辑标题与正文，再明确确认。
- 本机连接助手可将文字生成为真正的 PDF（使用已安装 Microsoft Edge 无头打印），也可保存 Markdown。
- 导入已有 PDF 时保存副本，限 15 MB；不抓取远程链接，不自动认领模型提及的文件已经存在。
- 文件保存在当前 Windows 用户的 `%LOCALAPPDATA%/LearnFlowAssets`，独立于程序更新目录。每份资料随机编号，不接受浏览器提供任意磁盘路径。
- 点击本机资料，通过系统文件关联打开。PDF 默认阅读器是 WPS 时由 WPS 打开；程序不会更改默认应用。也支持下载副本与确认后移除。
- 静态网站用 IndexedDB 保存 PDF/Markdown，支持预览和下载。浏览器模式不直接启动 WPS；下载后从系统打开，或进入本机版。
- 资产不包含在原有学习偏好 JSON 备份中；可逐份下载，浏览器清理站点数据会清除浏览器中的资料。本机目录中的文件独立保留。

## 验证

`node scripts/test-backend.mjs`：原有 30 项接口与 MCP 回归检查。

在本机服务器运行时执行 `node scripts/test-learning-assets.mjs`：15 项新增检查，包括保存确认、跨站拒绝、文件类型校验、真实中文 PDF 生成、下载、移除、模型建议分离与非完成回复的处理。脚本创建并移除自己的测试资产，在 `output/asset-validation` 保留测试 PDF。

浏览器实测逐题初始化、推荐路线、建议改写、真实模型建议、学习块草稿编辑保存、资产列表与重新打开；线上模式另测导入、预览和刷新后持久化。PDF 中文提取和页面渲染另行检查。

## 同一网页内的模型与文件能力

已配对的线上网页可通过本机连接助手调用真实学习模型，并保存或打开本机学习资产；未配对时使用浏览器存储。普通用户不需要填写 WorkBuddy 访问令牌。首次安装、浏览器本地网络权限和本机来源确认仍不能省略。正式腾讯 OAuth 需等待团队应用审核通过。
