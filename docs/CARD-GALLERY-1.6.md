# LearnFlow学习流动 · 策略广场 1.6.0

2026-09-08

策略广场换成可操作的立体卡片展台。按住卡面左右拖动，松手后落到一张卡片；鼠标移动时，卡面的角度和高光跟着变化。每种学习方法都有自己的立体插画，沿用已确认的 F 标志和 LearnFlow学习流动名称。

## 使用

- **挑卡片**：拖动展台、点击侧面的卡片、使用左右按钮，或点击下方的方法索引。展台取得键盘焦点后，方向键切换，Home / End 跳到首尾。
- **看步骤**：点击卡面右下角的翻面按钮。背面可以打开完整说明、个人评分以及 JSON / SKILL.md 导出。展台取得键盘焦点后也可按回车翻面。
- **收藏与启用**：正面提供收藏、启用和停用。启用状态仍参与学习对话中的策略选择，原有个人数据继续使用。
- **找方法**：搜索、场景筛选和收藏筛选保留。需要同时比较时可选择“全部展开”。
- **制作卡片**：输入名称、简介、步骤和标签，选择场景及四种配色，右侧实时预览卡面。保存后回到新卡片；在背面的完整说明中点击“编辑卡片”可以修改原卡，保留 ID、收藏及使用记录。
- **手机**：横向划动切换卡片，纵向划动滚动页面，保留双指缩放。系统或设置中的“减少动态效果”会关闭倾斜与过渡，切换直接完成。

## 验证

在 Edge 实际浏览器中完成 25 项展台检查、23 项制卡检查，并通过原有聊天与资料流程的 23 项回归检查。包括真实鼠标拖拽、浏览器触摸事件、翻面点击、搜索与筛选、收藏启停、保存与编辑、60 字标题、160 字说明、手机布局和减少动画。未出现页面脚本错误。

验证过程中修正了停顿后松手仍有过大惯性、点击背面文字意外翻回、翻面时旧动画继续移动等问题。测试使用独立浏览器数据和合成接口，没有调用用户模型或发送 QQ 消息。

本机验证记录位于 `output/card-gallery/`，包含 `gallery-checks.json`、`studio-checks.json`、`studio-edit-checks.json` 及桌面、手机截图。聊天回归结果位于 `output/ui-redesign/shell-checks.json`。

## 交付范围

纯 HTML / CSS / JavaScript 实现，插画在本机绘制，无新增前端依赖，无持续播放的后台动画。更新内容已纳入静态部署包和连接助手安装包。

卡片、收藏和评分仍保存于当前浏览器；此轮不引入线上社区或自动同步。原 PDF、答辩 PPT 和 Buddy 宿主插件没有因这次网页视觉更新而重新打包。没有收到指定的 Astra 演示链接，因此本版按“可拖动的 3D 卡片展台”实现，不声称复刻某个尚未确认的官方演示。
