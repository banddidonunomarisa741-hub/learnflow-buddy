# 学习流动：可核验研究与产品依据

核验日期：2026-09-06。本文不是实测报告。**事实**来自明确来源；**判断**是团队可争辩的分析；**计划**是尚待执行的设计。腾讯接口和发布资格以同目录 PLATFORM-VERIFICATION.md 的专项核验为准。本文没有把笔记中的日期、评分、市场规模或合作期待升级为事实。

## 1. 产业命题与政策

**事实。** 教育部等五部门《“人工智能+教育”行动计划》（教科信〔2026〕1号，落款 2026-04-02）提出建设人工智能学习社区、鼓励师生参与开源生态、评估教育智能体，并将未来学习中心与项目式、探究式场景纳入建设方向。第十一、十二条与本项目最相关。本次已读取官方全文；浏览工具直连超时后通过本地 HTTP 客户端获取。[教育部通知原文](https://www.moe.gov.cn/srcsite/A16/s3342/202604/t20260410_1433240.html)

**判断。** 项目的政策契合点是学习资源与方法共建、学习者自主选择、可核验的过程支持。政策存在不能证明本团队获得官方背书、项目立项、资金或示范基地资格。

**尚未核验。** 原笔记所称 2026 企业命题组评分 30/20/20/20/10、本命题编号 2562、校内赛和报名组别，尚未找到本次可核对的原始规则附件。应在实际报名页或学校通知中补齐附件、日期和组别，答辩材料暂不引用分值。

## 2. 官方竞品与相邻产品

这里比较公开能力和本项目拟验证的差异，不作未执行的性能排名；“未见公开说明”不能改写成“不支持”。

### ChatGPT 学习模式的准确时间口径

OpenAI 在 **2025-07-29 发布说明**中介绍了苏格拉底式提问、分块讲解、利用以往聊天记忆个性化和理解检查，并说明初期由定制系统指令驱动。该事实说明高质量教学行为可以由指令与产品流程组织，并不证明当前版本“仍然只有提示词”。当前帮助文档仍提醒学习模式可能出现错误或直接给答案。[OpenAI 原始发布说明](https://openai.com/index/chatgpt-study-mode/)

竞品结论应写为：**学习流动尝试把教学策略变成学习者掌握的版本化资产，并将学习过程变成可核验记录；其增量价值尚需同模型、同任务测试。**

### 腾讯其他教育 Buddy 的核验边界

本次找到明确官方来源的教育 Buddy 是 LearnBuddy；WorkBuddy 的专家/专家团是可比的生态载体。未找到足够依据支持一份“腾讯旗下其他教育 Buddy 完整名单”，因此不捏造产品名或功能排名。社区文章、第三方专家和腾讯官方产品应分开登记；托管在腾讯云开发者社区的个人文章不自动等于腾讯官方声明。

## 3. 学习策略的研究基础及其边界

| 机制 | 已核验文献与结论范围 | 可采用的产品动作 | 不应据此声称 |
| --- | --- | --- | --- |
| 检索练习 | Roediger & Karpicke（2006）在文本学习实验中比较再学习与回忆测试，延迟测验支持测试效应 | 先隐藏答案，用户回忆，再核对与反馈；之后安排延迟复测 | 每个学科、年龄和本平台都必然产生相同比例的提分 |
| 间隔练习 | Cepeda 等（2006）元分析指出学习间隔与最终保持时距共同影响保持 | 记录最近检索结果与计划复测日；允许调整期限 | “间隔越长越好”或论文直接证明某个固定排程算法 |
| 方法筛选 | Dunlosky 等（2013）综述将练习测试、分散练习评为高效用策略，同时讨论适用条件 | 首批默认卡优先选可操作、可检查的机制 | 将所有挂名学习法一律当成同等强度证据 |
| 个体偏好 | Pashler 等（2008）综述认为感官学习风格匹配缺少足够的教育应用证据 | 允许选表格、图片、长短与解释风格；把偏好当偏好 | 测出“视觉型/听觉型”后便能保证教学最优 |

**费曼式复述与苏格拉底式追问。** 可以作为面向用户的易懂名称。产品验收应检查用户是否独立解释、能否举反例或迁移，而不是假定贴上名人标签就有统一、最优的实验方案。词根词缀适合可解释的词汇，不能对所有单词强拆伪词源；配合语境与回忆测试更便于核验。

**鼓励与自律。** 个体偏好可用于减少厌烦，但系统不能从“连续未完成”直接推断懒惰、心理障碍或认知类型。选择题只询问会改变系统行为的目标、时长、资料类型、引导程度和提醒偏好。具体鼓励时机属于产品规则，尚无本项目实测证据。

## 4. Skill 与 MCP 的关系

**事实。** Agent Skills 是开放的轻量格式：以 SKILL.md 组织任务说明，可附带脚本、参考资料和模板，按需加载。MCP 是 AI 应用连接外部系统、数据和工具的协议。[Agent Skills 规范介绍](https://agentskills.io/home)、[MCP 官方介绍](https://modelcontextprotocol.io/docs/getting-started/intro)

**架构判断。** 不需要把每张卡变成 MCP 服务。建议分四层：

1. **学习方法层**：简短 Skill，列适用情境、步骤、输出、边界和验收。
2. **状态层**：使用独立版本的数据结构记录偏好、任务、事件与证据。
3. **适配层**：通过宿主公开工具或 MCP 读取资料、写入状态、请求授权后发送消息。
4. **评测层**：换模型或宿主后跑固定案例，比较格式、约束、引用和教学行为。

可迁移的是清晰的任务规范、数据与经过验证的工具实现；不能保证“任何模型无损运行”。权限、执行环境、上下文长度、工具发现与格式遵循都可能改变效果。确定性脚本也会受操作系统、依赖和权限影响，不能称“永远不失效”。

## 6. Token、评分与推荐的正确定位

**产品建议，尚待验证。** 保留用户希望的 token 使用量展示，并区分 API 返回的真实 usage 与演示估算。token 是使用量和成本指标，受输入长度、模型分词、回答冗长程度等影响；不是学习效果指标。

本地 MVP 的星级应标“我的帮助度”，没有后台的广场不能显示成真实跨用户口碑。后续社区可同时显示星级、有效学习块数、复用天数和样本量，token 只对“已使用”的可信度作有限贡献，不能线性加权。

一种可测试的候选方案：评分权重主要随有效学习块和复用天数增长，并设上限；token 贡献限定在小范围且使用对数/封顶处理。未授权提供使用记录者仍可评价。将“内容冗长但无学习证据”的高 token 会话降权；不收集对话原文来换排名。该方案是治理设计，不是已验证的公正算法。

推荐触发可基于用户主动探索、完成一个周期或持续遇到同一困难；给出为什么推荐，并保留当前策略。不能为了增长消费而频繁换卡，也不把低使用量等同于学习失败。

## 7. 最小验证计划

以下为执行计划，不填造结果。

**工程验证。** 冻结至少 12 个场景，覆盖三学习入口、记忆关闭、拒绝策略、任务中断、假性理解、高信心错误、来源不足、数据导出删除、提醒降频与模型迁移。对比裸底座、普通学习 Skill、学习流动，保持模型、材料、任务、时间预算和权限相同。每条件每场景重复两次；随机呈现给两名独立评分者，记录分歧。

**试用验证。** 阶段一计划邀请 8-12 人开展主持式可用性测试；阶段二计划招募约 30 名成年大学生，开展 2-4 周形成性试用，包含 7 天延迟测验。人数、周期和测验均为计划，不是已完成招募或已有成绩数据。便利样本只支持可用性与初步学习流程判断；长期教育效果需要更严格的分组与足够样本，不预先承诺提分。

| 指标 | 分母与判定 | 避免的误用 |
| --- | --- | --- |
| 约束满足率 | 所有受测计划中同时遵守时长、截止日期和启用策略的计划比例 | 拆成多个容易满足的小字段放大结果 |
| 闭环完成率 | 具备目标、动作、检验和复盘的完整场景 / 全部预定场景 | 只统计成功打开页面的人 |
| 来源支持率 | 可被指定材料支持的抽检事实陈述 / 全部抽检事实陈述 | 把有链接当作来源真的支持 |
| 状态恢复准确率 | 中断后正确恢复的任务和证据字段 / 全部测试字段 | 用模型自述“已记住”代替检查 |
| 自主权保持率 | 正确尊重用户选择的关键节点 / 全部关键节点 | 用默认勾选冒充同意 |
| 第 7 日留存 | 第 7 日有有效学习块的用户 / 首次完成学习块的用户 | 将任意七天内三次使用称作 D7 留存 |
| 七日复用率 | 七天内至少三次自发有效学习循环的用户 / 初始样本 | 混同满意度与学习效果 |
| 延迟检索表现 | 对指定知识点延迟作答的结果，按前测和缺失情况报告 | 把模型输出分数当正式考试成绩 |
| 成本与纠正轮数 | 完成每个有效学习块的真实 usage、耗时与用户纠正轮数 | 以 token 越多越好作为目标 |

## 8. 产业价值、成本与边界

**可以论证的企业价值。** 校园原生场景、短而可执行的策略库、可审计学习数据结构、同模型评测集和学生反馈能够作为腾讯的候选教育资产。企业是否愿意采纳、接口是否开放、主体是否满足资格，是待验证合作条件。

**不能声称的结果。** 本文没有用户总量、试点学校、付费转化、营收、节省成本或学习提升的已实现数据。中国所有在校生人数不应直接当可服务市场。先估计团队可触达的课程、社团与学习小组，再用激活和留存构建需求证据。

**成本模型。** 静态页面可低成本分发；远程模型推理仍有网络、账户配额与实际算力成本。单位学习块成本可按真实输入输出 usage、对应模型价格、工具调用成本与必要服务成本计算。价格未核验时不填写人民币结论；有免费静态托管不等于全系统永久免费。

**开源路线。** 初期发布策略规范、前端、文档、原创样例和评测协议；社区修改保留版本与来源。后续企业对接可以谈新增开发、托管和服务，但已按开源许可证发布的历史版本不能被宣传成可随意撤回他人既有许可。具体法律与商标安排需按最终合作文件核对。

## 9. 对外表述检查

- 用“降低获得方法支持的门槛”表述教育普惠愿景；首轮没有农村及未成年样本时，不称教育公平问题已被解决。

- 用“用户确认后提炼策略”表述记忆进化；不声称模型权重更新、自动训练或人格诊断。
- 用“面向 Buddy 生态的应用原型/待上架包”表述发布状态；账户认证和平台审核不能由页面完成代替。
