# LearnFlow学习流动 · 对话功能更新

更新日期：2026-09-06；本机连接助手版本：1.3.0。

正式名称：LearnFlow学习流动。网站与交付材料使用团队确认的白色流动 F 标志。

## 用户操作

1. 点顶部“连接学习助手”。首次使用下载并解压连接助手，双击“安装连接助手.cmd”；安装过旧版的用户也需运行一次新版安装文件。
2. 本地网页点“同意连接并验证”；线上网页点连接后在本机窗口确认来源。服务未启动时尝试唤起已安装的助手。浏览器可能要求允许打开应用、访问本地网络或弹窗。
3. 等待短回复验证，看到“已实际回复，可以开始学习”，点“开始学习”。无需手工复制客户端访问令牌。
4. 输入框上方选择模型，拖拽图片或文件到学习区，或点“图片 / 文件”；截图可直接粘贴。检查预览和提取说明，再发送。
5. 回答中显示本轮请求的模型。失败会显示原因，并保留草稿与附件用于重试。

连接许可只授权当前受信任网站、最长 8 小时。连接测试会消耗账号额度。断开网页连接不等于退出桌面客户端账号。

## 支持范围

|输入|当前行为|
|---|---|
|PNG / JPG / WebP|原始图片以多模态消息传给模型；每张最多 5 MB。模型是否能读图取决于所选模型与账号。|
|PDF|在浏览器本机用 PDF.js 提取文字，最多前 30 页、60000 字符，发送前显示实际提取页数；不包含页面图片与版式。扫描版请用页面截图。|
|TXT / MD / CSV / JSON|读取文字，最多 60000 字符；超限会显示截取说明。建议 UTF-8 编码。|
|Word / PPT 等|明确提示先导出 PDF，不显示虚假的上传成功。|

每轮最多 4 个附件；文档每个最多 10 MB，合计传输受约 12 MB 限制。附件只随当前这一轮发送，后续重新分析原件请再次附上。原始附件不写入聊天备份；“学习资产”仍需要另外确认保存。

本机模型列表读取已安装客户端的 `--help` 声明，不保证每个模型都有账号权限或额度。兼容接口从 `/models` 获取列表，若服务不支持则显示用户配置的默认模型。正式 WorkBuddy 本地助理文字通道仍使用宿主默认模型，明确不支持此次附件与模型切换。

## 验证记录

- 本机真实调用：自动模型正确读出图片中的 `LF 7294`。
- 网页端真实调用：选择 `hy3`，提取 17 页方案 PDF 后正确回答其中三大学习场景。
- 网页端：连接验证成功提示保持可见；15 个客户端模型选项；文件拖拽、附件预览、网络失败时草稿与附件恢复。
- 自动检查：30 项原有后端检查、19 项配对检查、14 项新增模型与附件检查。新增测试覆盖模型参数实际转发、图片原始字节、文档正文、无授权来源拒绝、畸形附件与验证授权。

这些结果只证明对应本机版本与测试账号上的联调，不等于腾讯官方 OAuth 审核完成、LearnBuddy 原生 API 接入或所有模型都已逐一验证。
