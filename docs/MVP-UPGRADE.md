# LearnFlow学习流动 · MVP 更新

连接助手 1.4.0，2026-09-06。正式名称与 F 标志保持一致。

## 网页现在怎样使用

首次打开会逐题询问学习场景、目标、可用时间、引导方式、语气、鼓励偏好和记忆开关。可以逐项选择，也可以先用推荐路线；以后仍能修改。

点击“连接学习助手”，在本机窗口确认请求来源。连接后会发送一次简短测试；模型成功回复才显示验证成功。模型菜单提供搜索、键盘选择与当前模型标记，列表来自实际通道，不填写未经核实的积分价格。

回答逐段出现，可以停止或在失败后重试。表格、代码、列表和链接按内容排版。模型生成的后续选项放在回答下方，点击可继续，也能先改写；调整学习方法的入口仍保留。图片可拖拽、粘贴或选择，PDF 和文字文件可加入当前轮，发送前可以移除。PDF 当前提取文字，不含扫描件 OCR。

有用的回答和学习块可以先核对，再确认保存为学习资产。本机助手保存的 PDF 可以交给系统默认阅读器打开；是否使用 WPS 取决于电脑的默认应用设置。只有静态网页时，资料保存在浏览器，可以预览或下载。

## QQ 是第一条腾讯连接

连接器页打开本机扫码窗口，由本人在手机 QQ 完成腾讯授权。之后，发给机器人的私聊进入 LearnFlow 收件箱；点击“带到学习空间”成为草稿，再由本人发送给模型。收到的附件暂不自动下载。

回复 QQ 或设置单次学习提醒时，要确认收件人、内容与时间。QQ 身份凭据只在本机服务内存中，退出或断开后清除；待发提醒和收件记录也随之清除。目前需要电脑开机、联网并保持助手运行。没有设置云端后台，也不承诺离线提醒或无限发送额度。

扫码任务创建与轮询已连接腾讯真实接口。收发、取消、重复发送、断开和提醒错过时间等逻辑使用隔离测试验证；本人完成扫码前，真实 QQ 消息收发仍待验。见 [QQ 接入说明](TENCENT-CONNECTORS.md)。

## “在宿主里面跑通”是什么意思

LearnBuddy 是宿主。使用它自己的模型、技能和工具入口，完成学习、整理草稿、本人确认保存、再次打开资料，才是宿主内的使用过程。

本次扩展通过正常插件机制安装到 LearnBuddy，提供学习技能、专家与 MCP 工具。MCP Apps 面板是对话里的交互区域，能否展示以及展示在哪由宿主决定；这不等于取得修改 LearnBuddy 整个首页和侧栏的能力。模型菜单、会话布局等仍属于宿主本身。

网页与宿主插件是两个可运行入口。当前各自保留学习资料，未自动同步；可通过文件导入导出迁移。安装步骤、实际验证与限制见 [LearnBuddy 安装说明](LEARNBUDDY-INSTALL.md)。

## 申请通过后还需要什么

公司登记、企业开发者认证、应用创建审核和配置发布审核是不同环节。本次工程按官方组件要求准备，仍需控制台分配真实资源 ID、确认模型及权限、取得官方导出配置并预览。公共自动启用连接器若要求 OAuth，还须部署相应服务并完成授权联调。

这些不能用本地生成的 JSON 冒充完成。按 [Buddy 提审检查表](BUDDY-RELEASE-CHECKLIST.md) 填入实际账户资料后逐项验证，无需重做学习策略与本机组件。
