## 复现

本机服务运行时执行：

```powershell
node docs/validation-script.cjs
node scripts/test-rich-text.mjs
```

回归脚本默认使用 Edge 和 4173 端口。可用 `LEARNFLOW_TEST_URL` 指定测试页面，`PLAYWRIGHT_MODULE` 指定 Playwright 模块目录；也支持从 `CODEX_NODE_MODULES` 或当前用户的 Codex 运行时目录查找。自定义浏览器可设置 `CHROME_PATH` 或 `BROWSER_CHANNEL`。

Markdown 安全和渲染检查另有 **12 项通过**，覆盖 HTML、脚本、危险链接、代码原文、表格及流式元数据隐藏。真实授权、附件读取和流式回复的实机记录见 `output/playwright/ux-verification.json`，与本页的只读 fixture 验收分开记录。
