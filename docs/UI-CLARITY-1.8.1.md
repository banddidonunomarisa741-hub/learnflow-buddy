# LearnFlow学习流动 1.8.1 · 字号与界面精简

本版按提供的 Buddy 界面参考调整网页，不改变品牌标志或模型接口。

- 主导航和正文16px；常用控件15–16px；必要次要文字14px；页面标题26–32px。
- 功能图标显示16×16px，24单位视图内线宽1.8，等效显示线宽1.2px。使用既有自绘线性图标，并不声称使用腾讯官方素材。
- 教师页删除口号、英文眉题和常驻说明条，直接呈现课程与操作。课堂能力边界收进“课堂说明”。
- 侧栏、设置、聊天、资料和任务看板移除重复说明；重要的保存、分享、覆盖导入和模型错误保留在相关操作处。
- 策略卡保留立体交互、详细方法与实例；放大文字后调整内容空间，按钮完整显示。

本版不调用真实模型验收、不发送QQ。开发使用隔离的浏览器资料；字体尺寸、图标尺寸、控制交互、1440px桌面、390px手机、720px重排与深色模式分别检查。结果在 output/ui-cleanup/ 与组件验收记录。

代码与发布包均为1.8.1，本机接口协议继续使用1.7.0。当前线上入口为 [GitHub Pages](https://banddidonunomarisa741-hub.github.io/learnflow-buddy/?v=1.8.1)；Netlify因账户额度耗尽仍保留1.7。
