# LearnFlow学习流动 · 策略使用、分享与版本

网页版本：1.9.0。更新日期：2026-09-08。

## 从哪里开始

左侧进入“我的策略”。这里可以查看已启用、自己制作、收藏和全部卡片。每张卡可开始学习、看使用记录或分享；点标题查看完整做法、示例、边界和反馈。策略广场原有的立体卡片展示保留。

“开始学习”将目标策略优先加入本次会话，并把起始问题放进输入框，由用户编辑、发送。不会因为启用卡片很多而悄悄漏掉当前选择的那张。

## 用量记录

- 仅在收到明确完成的模型回复后记录。任务处理中、待用户操作、阶段文字不算完成；失败、中断可能仍消耗上游用量，当前记录不是完整账单。
- 记录时间、模型、参与卡片的编号和内容版本、整轮 Token 与分摊量，不记录对话正文或凭证。
- 多张卡等额分摊模型返回的整轮 Token，余数逐张分配，合计严格一致。分摊值不代表每张卡可独立测量的消费。
- 预设演示仅记估算；接口没有返回用量时保持未知。Token 不等于腾讯积分，不用于判断学生掌握程度。
- 每条记录按本机生成的回复编号去重。最多保留 3,000 条完成记录和 6,000 个近期去重编号；达到上限时明确显示截断。
- 旧版只有累计量的历史数据继续保留在完整备份，不凭空补出逐轮记录。恢复备份的逐轮记录单列为自述，不提高新设备的本机实测量。

## 分享与采纳

“分享”可以复制链接、下载 JSON 卡片或 SKILL.md。链接将卡片编码在 `#` 后的片段里，不依赖卡片存储服务器。内容过长时改用文件。

分享只包含卡片白名单内容：标题、介绍、步骤、标签、场景、实例、依据、边界和版本来源。不会附加对话、记忆、Token 账本、账户资料或模型凭证。卡片中主动填写的文字会按预览分享，发布前应检查。

接收者打开链接或导入 JSON 后，先看到完整预览，确认后才采纳。同一来源、同一内容版本重复导入不会复制一张新卡。

## 修改与反馈

“改成我的版本”复制方法并保留来源版本。修改核心内容后产生新内容指纹，旧的使用记录和反馈仍关联旧版本；单纯打开编辑器原样保存不会生成另一版本。指纹用于比较内容，不是作者身份签名。

反馈包含 1–5 分、是否有帮助、具体文字和当时的使用汇总。个人使用参考权重采用 `min(1, log(1 + 当前版本的模型分摊量) / log(10001))`，演示不增加权重。此规则提示使用背景，不能证明效果或抵御客户端篡改。

反馈可单独导出，下载前再次预览。接收者导入时需匹配卡片和版本，并明确标为“外部反馈 · 自述”，不纳入本机实测量。

当前是链接/文件互传和本机反馈，并无公共卡片数据库、跨设备同步、公共评分或防刷排行。多人社区仍需 LearnFlow 自己的后端和身份机制，不能把本机统计称为社区统计。

## 本轮模型实测

通过本机 WorkBuddy 适配通道发送了一个词根练习问题，实际回复模型为 `glm-5.3`。接口返回整轮 **3,843 Token**；两张参与策略分别记录 **1,922** 和 **1,921**，合计一致。积分没有由该通道返回，因此仍显示未提供，不以 Token 推算。

另一次连接验证实际模型为 `minimax-m3`、返回 3,366 Token。连接探测不是学习对话，未混入策略使用账本。上述仅为本机本次验证，不保证所有用户、所有模型都能返回用量。

## 与用户提供的腾讯接口文档的关系

认证授权、本地助理、云任务、ACP 与会话产物接口是执行及通信能力，不是策略社区数据库。兑换码接口用于发放积分，不是扣费量查询。

正式网页登录授权与云任务联调仍需要已启用的应用身份、获准权限和用户授权。前端不得存放 `client_secret`。本轮复用已可用的本机模型适配，不宣称已完成待审核应用的正式 OAuth 登录、云端 ACP 或公共应用发布。

官方接口参考：[WorkBuddy Open API](https://open.workbuddy.cn/docs/openapi)。本轮同时对照用户提供的完整接口文本逐项核对。

## 验证方式

账本纯函数测试覆盖整数分摊、未知用量、去重、保留上限、版本、外部反馈、分享白名单和长度约束。浏览器回归覆盖分享采纳、编辑、反馈互传、备份恢复、异常输入和移动端；模型调用的真实验证与模拟协议测试分别记录。
