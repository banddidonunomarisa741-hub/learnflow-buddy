# LearnFlow学习流动 1.8 · 项目与交互

本轮围绕同一个学习空间整理侧栏、教师页、设置和弹层。F 标志与 LearnFlow学习流动名称保持不变。

## 设计与技能来源

按用户要求，从 GitHub 安装并阅读了两项设计技能，安装在本机 Codex 技能目录；技能用于辅助开发，不是网页运行时依赖。

- [Anthropic frontend-design](https://github.com/anthropics/skills/tree/41bbe19d1a1a7eaab5e7bb9050a417e5c6cffc8f/skills/frontend-design)：围绕实际产品内容设计、控制装饰、检查截图与组件层级。
- [Vercel Labs web-animation-design](https://github.com/vercel-labs/open-agents/tree/cf865e94de7729751c747171785b6ce57e7b178c/.agents/skills/web-animation-design)：动作反馈、缓动、持续时间、手势与减少动态支持。

遵循用户已确定的暖橙色，不因技能推荐改变品牌。主色为橙色 `#ED7B32`，深橙 `#A44714`，纸白 `#FFFEFC`，暖灰 `#F8F5F1`，描边 `#E9E3DB`，正文 `#2B2825`。文字沿用适合中文界面的系统无衬线字体，字号区分正文、操作与辅助信息。界面左侧负责项目和会话，中央优先展示当前学习内容。

```text
LearnFlow        当前对话 / 教师课程 / 设置
新对话           ┌────────────────────────┐
搜索             │                        │
常用入口         │      当前学习内容      │
项目       ＋    │                        │
  六级复习       └────────────────────────┘
    阅读证据链         输入 / 核验 / 保存
  概率论
未分组对话
```

对照需求后，保留现有的立体策略展台作为视觉重点。学习对话不增加持续漂浮或循环光效；动效围绕拖放、开合、切换和确认，让操作结果更清楚。

| 原体验 | 本轮处理 |
| --- | --- |
| 对话平铺，没有项目入口 | 添加项目分组、项目内新对话、移动菜单和拖放落点 |
| 教师页独立使用大片绿色 | 统一暖橙按钮、奶油色课程区域、暖灰边框；语义状态保留少量色彩 |
| 弹层和按钮缺少一致反馈 | 统一短时过渡与按压反馈，减少动态时停用 |
| 拖动后难以判断是否放对 | 展示拖动预览和目标，支持取消和键盘移动 |

## 验收清单

发布前用独立浏览器数据检查，不调用真实模型或 QQ：

- 项目创建、改名、折叠、展开、删除后对话保留。
- 对话拖入、移出项目及重排；拖到无效区域、取消拖动。
- 键盘和触控的替代操作，窄屏不会挤出视口。
- 移动对话后再次打开，标题、正文和输入草稿仍正确。
- 项目内新对话，分组在刷新后保留；不改变原有对话保存开关。
- 备份恢复带上项目分组；清除数据同时清除分组。
- 教师页、设置、模型选择和资料页的浅色、深色与减少动态。
- 流式内容更新不会重复播放进场动画。

实际结果与截图保存在 `output/design-upgrade/`，发布记录以该目录的最终验收文件为准。

## 数据与版本

项目分组只保存项目名称、折叠状态、对话编号与顺序。对话原文仍遵循原有保存设置，不因拖拽而开启持久保存。项目文件夹只用于组织对话；课程 Demo、任务看板及模型接入的能力边界沿用 1.7。

网页版本为 1.8.0，本机接口协议沿用 1.7.0。本轮不修改模型调用、授权凭据或 QQ 发送逻辑。

## 实际验收结果

2026-09-08：独立浏览器中的侧栏组件检查 28 项、全站动效检查 31 项、完整应用集成检查 14 项均通过。另检查了教师端浅色、深色、390px 排版、角色切换、按钮反馈与减少动态。

集成验收实际导出 4 段示例对话和 2 个项目，清除后恢复，归属与顺序一致。损坏的项目备份被拒绝，旧版备份可以恢复。关闭学习记忆后，项目名称和编号继续保存，对话原文不会因此写入浏览器。截图检查覆盖桌面、手机、深色设置、模型弹层与教师页。

所有本轮验收均使用隔离的演示资料，不消耗真实模型调用，也未发送 QQ 消息。机器结果位于 `output/design-upgrade/integration-checks.json`、`output/design-upgrade/motion-checks.json` 和 `output/sidebar-release/sidebar-checks.json`。
